# 具身智能日报 · 2026-11-15

**今日概览**：今天最重磅的两件事：一是 Genesis 团队发布全新机器人学习框架 **Eden**，主打"一次任务定义、仿真到真机贯通"，并称 coding agent 构建任务比 Isaac Lab 快 1.6–4 倍；二是 **OpenAI 再次解散独立机器人团队**，将研究人员并入主研究团队，押注 GPT-6 Astra 等通用模型直接驱动机器人——这引发了社区关于"通用模型能否跨越 sim2real 鸿沟"的热烈争论。此外，CoRL 2026 刚在奥斯汀闭幕，社区总结认为瓶颈已从策略架构转向数据与算力经济学；军用机器人公司 Foundation 被曝拖欠工资，CEO 个人借款买房引发质疑。

## 🧠 论文与研究

- **[kashu_yamazaki]** Genesis 团队发布机器人学习框架 **Eden** 🍎：一次任务定义即可贯通 sim-to-sim 与 sim-to-real，专为 agent 设计，coding agent 建任务速度比 Isaac Lab 快 1.6–4 倍。已开源（Apache-2.0）并上线 PyPI：`pip install eden-world`。（👍327 · [原文](https://x.com/kashu_yamazaki/status/2121634263963718118) · [开源地址](https://x.com/kashu_yamazaki/status/2121634272306205078)）

- **[yoshi_flux]** CoRL 2026 闭幕深度总结（2094 篇投稿、录取率 32.8%）：最佳论文 **SuperMimic**（UC Berkeley）用共享可微世界模型+短期想象 rollout 训练人形运动追踪，单卡 H100 约 3 小时 vs NVIDIA SONIC 的 2.1 万 GPU 时，并成功迁移至 Unitree G1；其他亮点包括 **GRAIL**（无真人拍摄生成 2 万+ 人形操作序列）、**EgoScale**（2 万小时第一人称人类视频的 VLA 缩放定律，R²≈0.998）、**DreamZero**（14B 世界动作模型，30 分钟玩数据适配新本体）、**π0.7**（把失败 rollout 和干预变成训练信号）、**RoboTTT**（测试时训练扩展至 8000 步上下文）、**T-Rex**（百小时触觉数据进动作环路）。核心判断：竞争重心从"扩大模型"转向"工程化数据飞轮"，触觉是下一个数据层。（👍108 · [原文](https://x.com/yoshi_flux/status/2121515389557580269)）

- **[wang_zhi]** 发布跨架构诊断 benchmark **Mind2Act World**：30 个仿真双臂任务、180 种配置（3 难度 × 干净/随机场景）、4500 条演示，专测高层推理如何转化为精细双臂执行。由清华、剑桥、牛津、CMU 等十余家机构联合完成，排行榜已上线。（👍11 · [原文](https://x.com/wang_zhi/status/2121514098987057498)）

- **[HuggingPapers]** 新框架 **A2-MEAS**：以代码为扩展接口的具身多智能体系统，结合 MetaBrain 推理、诊断智能体与学习式纠错接口引导 VLA 策略。BEHAVIOR 2026 Q-score 0.6411，RoboTwin 2.0 成功率 95.05%，12 项真机任务 57.92% vs π0.5 的 26.67%。（👍24 · [原文](https://x.com/HuggingPapers/status/2121455383755817113)）

- **[LeoKharon]** 触觉数据统一建模新工作 **UVTA**（北京通研院、Sharpa、上交大）：用 22 自由度被动外骨骼+指尖力敏电阻+腕部鱼眼相机采集人类触觉演示（5 个接触丰富任务各 1000 条人类+150 条机器人演示），ViT 编码视觉+20 维触觉 token，扩散策略头输出 31 维动作。值得注意：人类数据在此作正则化而非替代机器人数据。（👍12 · [原文](https://x.com/LeoKharon/status/2121589865384976800)）

- **[XianghuiXie]** **PiHand**：在潜空间高效进行 RL 后训练，单一潜空间即可学习不同物体与任务，面向灵巧操作。（👍24 · [原文](https://x.com/XianghuiXie/status/2121349062255608095)）

- **[ekinoks_26]** 真机评测网络 **RoboColosseum**（BitRobot 与 Hugging Face、NUS、新加坡具身智能中心共建）首日结果惊人：Unitree G1 上所有被测策略在 5 个任务中**无一完成**，平均进度仅 13.3%–23.2%。4 种本体共 1.5 万次试验，失败 rollout 全部以 LeRobot 格式公开；901 组匹配对比中，xAI/Anthropic/OpenAI 的前沿通用模型在 394 例中超越专用机器人策略（对方 265 例）——通用推理正在"零训练"进入操作领域。（👍114 · [原文](https://x.com/ekinoks_26/status/2121619161285542246)）

- **[jinwanxin]** ASU IRIS Lab 招收 2027 秋全奖博士生，方向：多物理引擎与数据生成、生成式机器人学习、agentic robotics。（👍139 · [原文](https://x.com/jinwanxin/status/2121445204620103845)）

## 💬 观点与讨论

- **[stevencheng]** 对 OpenAI"通用模型直接驱动机器人"的嘲讽一针见血：机器人还在撞 sim2real 鸿沟和关节力矩限制，工程师看到的只是"长了夹爪的聊天机器人"。（👍29 · [原文](https://x.com/stevencheng/status/2121366393316888816)）

- **[MarcJSchmidt]** 批评密集模仿学习提速"从一周到几分钟"几乎没有实际商业价值：瓶颈从来不是模仿本身而是数据与泛化，真正要的是消除 sim2real 鸿沟，而不是让机器人跳舞或复现动画库。（👍12 · [原文](https://x.com/MarcJSchmidt/status/2121699494681096568)）

- **[aahoussaini]** 一则轶事引发讨论：参观某公司 HQ 时发现其"AI/机器人学习"团队不认识 Sergey Levine 和 Russ Tedrake，甚至不知道 NeurIPS——机器人学习团队与学术前沿脱节的现象值得警惕。（👍21 · [原文](https://x.com/aahoussaini/status/2121651585763975342)）

- **[MeshNeuro]** 人形机器人进入医院、共享仓库等人类担责场所的前提是"可验证自主性"：每个动作执行时都在批准包络内且可出具证据，否则部署永远停在试点阶段。（👍51 · [原文](https://x.com/MeshNeuro/status/2121498471199027485)）

- **[TheCaptainEli]** 重提马斯克最被低估的观点：工厂比产品重要——"制造机器的机器"远比机器本身难。百万级廉价制造人形机器人本质上是工厂问题，而特斯拉花了十年学解工厂问题。（👍25 · [原文](https://x.com/TheCaptainEli/status/2121488065583571181)）

- **[guannanqu]** CoRL 2026 GPU 加速 sim-to-real 工作坊报告："测试时采样的力量：从仿真器到世界模型"——test-time sampling 成为会议热点之一。（👍11 · [原文](https://x.com/guannanqu/status/2121627920191873419)）
